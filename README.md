# Dinevoro Backend

Express + MongoDB API for Dinevoro.

## Setup

```bash
cp .env.example .env.local
# set MONGODB_URI, JWT_SECRET, FRONTEND_URL
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Live: https://dinevoro-backend.onrender.com
